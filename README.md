## ⭐ Featured Project

### NOSTRA — Full-Stack Fashion E-Commerce Platform 🚀

**NOSTRA** is a full-stack fashion e-commerce application built with a **Django REST Framework backend and React 19 frontend**.

The project includes customer and admin workflows with a focus on REST API design, authentication, database relationships, security, performance and automated testing.

### 🔧 Backend

- Django
- Django REST Framework
- JWT Authentication
- SQLite
- RESTful APIs

### 🛍️ E-Commerce Features

- Product & Category Management
- Product Images
- Sizes, Colors & Variants
- Search, Filtering & Sorting
- Pagination
- Stock Management
- Cart
- Wishlist
- Address Management
- Checkout Flow
- Order History
- Order Cancellation
- Payment Attempt Flows

### ⚙️ Engineering Features

- JWT-based authentication
- Customer/Admin access control
- Ownership-based authorization
- Query optimization using `select_related` and `prefetch_related`
- Database transactions
- Row-level locking for stock-aware cart and checkout operations
- Automated backend testing
- **407 automated backend tests**

### 🎨 Frontend

- React 19
- Customer storefront
- Admin workflows
- API integration

### 📌 Current Status

**Functionally Complete — Not Yet Production-Hardened or Deployed**

The application currently uses SQLite locally and does not have a live production deployment.
